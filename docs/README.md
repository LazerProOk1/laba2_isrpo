# Geometric Lib

## Краткое описание
Библиотека `geometric_lib` на Python предназначена для вычисления площадей и периметров базовых геометрических фигур: круга, квадрата, прямоугольника и треугольника.

---

## Функции и параметры

### 1. circle.py (Круг)

#### area(r) — Площадь круга
* **Описание:** Вычисляет полную площадь круга по заданному радиусу.
* **Параметры:**

  | Имя | Тип | Описание     |
  | :--- | :--- |:-------------|
  | `r` | `int` / `float` | Радиус круга |
* **Возвращаемое значение:** `float` — Площадь круга.
* **Пример вызова:**
  ```python
  >>> area(5)
  78.53981633974483
  ```

#### perimeter(r) — Длина окружности
* **Описание:** Вычисляет длину окружности (периметр круга) по его радиусу.
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `r` | `int` / `float` | Радиус круга |
* **Возвращаемое значение:** `float` — Длина окружности.
* **Пример вызова:**
  ```python
  >>> perimeter(5)
  31.41592653589793
  ```

---

### 2. square.py (Квадрат)

#### area(a) — Площадь квадрата
* **Описание:** Вычисляет площадь квадрата по длине его стороны.
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `a` | `int` / `float` | Длина стороны квадрата |
* **Возвращаемое значение:** `int` / `float` — Площадь фигуры.
* **Пример вызова:**
  ```python
  >>> area(4)
  16
  ```

#### perimeter(a) — Периметр квадрата
* **Описание:** Вычисляет сумму длин всех четырёх сторон квадрата.
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `a` | `int` / `float` | Длина стороны квадрата |
* **Возвращаемое значение:** `int` / `float` — Периметр квадрата.
* **Пример вызова:**
  ```python
  >>> perimeter(4)
  16
  ```

---

### 3. rectangle.py (Прямоугольник)

#### area(a, b) — Площадь прямоугольника
* **Описание:** Вычисляет площадь прямоугольника по двум смежным сторонам.
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `a` | `int` / `float` | Длина первой стороны |
  | `b` | `int` / `float` | Длина второй стороны |
* **Возвращаемое значение:** `int` / `float` — Площадь прямоугольника.
* **Пример вызова:**
  ```python
  >>> area(4, 5)
  20
  ```

#### perimeter(a, b) — Периметр прямоугольника
* **Описание:** Вычисляет периметр прямоугольника (удвоенную сумму ширины и высоты).
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `a` | `int` / `float` | Длина первой стороны |
  | `b` | `int` / `float` | Длина второй стороны |
* **Возвращаемое значение:** `int` / `float` — Периметр прямоугольника.
* **Пример вызова:**
  ```python
  >>> perimeter(4, 5)
  18
  ```

---

### 4. triangle.py (Треугольник)

#### area(a, b, c) — Площадь треугольника
* **Описание:** Находит площадь треугольника по длинам трёх его сторон, используя формулу Герона.
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `a` | `int` / `float` | Длина первой стороны |
  | `b` | `int` / `float` | Длина второй стороны |
  | `c` | `int` / `float` | Длина третьей стороны |
* **Возвращаемое значение:** `float` — Площадь треугольника.
* **Пример вызова:**
  ```python
  >>> area(3, 4, 5)
  6.0
  ```

#### perimeter(a, b, c) — Периметр треугольника
* **Описание:** Вычисляет сумму длин всех трёх сторон треугольника.
* **Параметры:**

  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `a` | `int` / `float` | Длина первой стороны |
  | `b` | `int` / `float` | Длина второй стороны |
  | `c` | `int` / `float` | Длина третьей стороны |
* **Возвращаемое значение:** `int` / `float` — Периметр треугольника.
* **Пример вызова:**
  ```python
  >>> perimeter(3, 4, 5)
  12
  ```
